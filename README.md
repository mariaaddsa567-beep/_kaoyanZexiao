# 考研择校助手 · 408 专项

面向 985/211 计算机类考研（0812 计算机科学与技术 / 0835 软件工程 / 0839 网络空间安全 / 0854 电子信息）的择校决策工具。基于研招网与软科公开数据，提供 408 统考检索、分数线查询与「冲稳保」智能推荐。

## 功能

- **冲稳保推荐**：输入预估总分与画像（数学/英语类型、省份、985/211 偏好、政治/英语单科分），按三年加权预测线 + sigmoid 概率输出「过复试线概率」分层推荐，附计算依据与风险提示
- **一志愿决策卡**：一志愿只能报一所 → 自动给出 1 个主攻建议（稳档最接近 65% 概率），冲稳保转为调剂备选池
- **院校库检索**：仅 408 统考报考点过滤，支持省份/层次/学硕专硕/数英类型筛选，含学科排名与统考名额（不含推免）
- **分数线**：国家线（近 3 年）+ 34 所自划线院校公告线（OCR 提取），每条数据带来源与置信度标注
- **单科线校验**：政治/英语低于单科线时黄色警示「总分过线也无法进入复试」
- **志愿对比**：最多 5 所并排对比（排名 / 名额 / 校线 / 国家线），收藏本地保存

## 快速开始

仓库已附带全部原始采集数据（`data/*.json`），**无需重新爬虫**，建库后即可运行：

```bash
# 1. 安装依赖（建议 Python 3.10+）
pip install -r requirements.txt

# 2. 从原始数据构建 SQLite 数据库
python -m db.build_db

# 3. 启动服务
python app/server.py
```

浏览器打开 <http://127.0.0.1:5000>。

> 自划线校线 OCR 属于可选数据（建库时检测到 `data/zhx_scores_parsed.json` 自动写入）。仓库已含该文件，跳过爬虫与 OCR 步骤即可获得完整数据。

## 数据采集（可选，仅更新数据时需要）

管线均有断点续跑（已落盘的文件自动跳过），按顺序执行：

```bash
# 1. 主数据：软科排名 + 研招网专业目录（混合模式，约 568 组）
python scraper/run_all.py

# 2. 分数线：国家线 + 34 所自划线公告（含公告图片下载）
python scraper/fsx.py
python scraper/fsx_imgs.py

# 3. OCR 提取公告图片中的分数线（RapidOCR，267 张图较耗时，支持中断续跑）
python scraper/ocr_zhx.py
python scraper/parse_zhx.py

# 4. 重建数据库
python -m db.build_db
```

OCR 依赖需额外安装：`pip install rapidocr-onnxruntime`

## 数据置信度

| 置信度 | 含义 | 前端标识 |
|---|---|---|
| A | 官方结构化数据（国家线表格） | 绿色「置信A」 |
| B | 自划线公告 OCR 提取，建议对照原文图片核对 | 黄色「置信B·OCR」 |
| C | 无校级数据，以国家线为基准估算 | 红色「置信C·基准」 |

推荐结果中置信 C 或数据不足 2 年的院校只给出分数区间，不给具体概率。

## 项目结构

```
app/            Web 服务与前端（Flask + 原生 JS，单页三 Tab）
  recommender.py    冲稳保推荐算法（硬过滤 → 预测线 → sigmoid → 分层）
  server.py         REST API（/api/programs /api/recommend /api/schools ...）
  static/           前端页面
db/             数据库构建（build_db.py）与只读查询（funcs.py）
scraper/        采集管线（研招网 / 软科 / 分数线 / OCR）
data/           原始采集数据（JSON）+ kaoyan.db（gitignore，本地生成）
app/static/fsx/ 自划线公告原文图片（校线核对用）
```

## 预测算法（v1）

```
预测线 L = 0.5 × 去年年线 + 0.3 × 前年 + 0.2 × 大前年
σ = 近三年线标准差（下限 8）
过线概率 P = sigmoid((你的总分 − L) / (σ / 1.5)) × 院校修正
院校修正：自划线 ×0.95；统考名额 ≤10 人 ×0.92
分层：冲 P<35% ｜ 稳 35%~70% ｜ 保 ≥70%
```
